# X Autopilot — X (Twitter) 智能运营 Chrome 插件

基于大模型的 X 运营助手：**手动模式**在推文详情页抓取内容、生成评论并一键填入；**自动模式**按配额与拟人化节奏巡航时间线，执行点赞 / 评论 / 关注。

全程本地运行，API Key 只写入 `chrome.storage.local`，不经过任何第三方服务器。

---

## 快速开始

在 Chrome 打开 `chrome://extensions` → 打开右上角「开发者模式」→ 点击「加载已解压的扩展程序」→ 选择 **`dist`** 目录。

---

## 首次配置

1. 点击扩展图标（或 `Alt+Shift+X`）打开侧边栏 → **设置 · 模型**
2. 选一个预设（DeepSeek / Moonshot / 智谱 / 通义 / OpenAI / Anthropic），或手填 Base URL
3. 填入 **API Key**、确认 **模型名称** → 点「**测试连通性**」
4. 切到 **设置 · 数据与诊断** → 在已打开 X 页面的情况下点「运行」DOM 自检，确认各选择器命中


## 两种工作模式

### 手动模式

打开任意推文详情页（URL 形如 `x.com/用户/status/123`）→ 侧边栏显示「详情页」→

1. **获取内容** — 抓取正文、作者、上下文推文
2. 选一个**语气**（犀利洞见 / 支持探讨 / 提问追问 / 轻松幽默 / 亲身经历）
3. **生成评论** — 调模型产出，字符数实时校验
4. **仅填入** 或 **填入并发送**

勾选「生成后自动发送」后，生成即填入，延时 N 毫秒后自动点击发送按钮。

#### 打开详情页后自动执行

「获取内容」按钮下方有三个复选框，勾选后每次进入推文详情页会自动跑一条流水线：

| 开关 | 行为 |
|---|---|
| 自动获取内容 | 检测到 `/status/` 详情页时自动抓取正文 |
| 自动生成评论 | 抓到内容后自动请求 AI 生成（依赖抓取） |
| 自动关注博主 | 对当前页面的推文作者自动点关注 |

### 自动模式

设定每轮配额（点赞 / 评论 / 关注）与行为节奏后点「启动自动巡航」。流程：

```
导航到 x.com/home → 模拟滚动浏览 → 随机挑选未处理推文
  → 按概率点赞 → 按概率关注作者 →（达配额则）进入推文详情页发评论
  → 返回时间线 → 每个动作间插入随机静止 8~25s
  → 配额完成后冷却 15~30 分钟 → 下一轮
```

| 步骤 | 实现 | 为什么 |
| --- | --- | --- |
| 1. 进详情页 | `enterDetailPage(article)` | 轮询确认「URL 已切到 `/status/` **且** 主推文已渲染」才算就绪 |
| 2. 解析正文 | `extractDetail()` | 用详情页的真实长文喂给模型，而非时间线上的截断摘要 |
| 3. 展开编辑器 | `focusReplyEditor()` → `waitForMainArticle()` | 详情页异步渲染，主推文可能还没挂载，不能 `querySelector` 一次就判死 |
| 4. 注入 | `fillEditor(text)` | 走「只写不读」策略（见下文） |
| 5. 发送 | `submitComment()` | 可选，受 `autoSubmitComment` 控制 |
| 6. 返回 | `goBackToTimeline()` | 优先点 `[data-testid="app-bar-back"]`，退化到 `history.back()` |

## 项目结构

```
src/
├── background/service-worker.ts   轮次调度、alarm 计时、LLM 代理出口、作者主页关注编排
├── content/
│   ├── index.ts                   消息路由 + 自动轮次自驱执行体
│   ├── dom-extractor.ts           推文/作者/编辑器抓取与选择器自检
│   ├── dom-actions.ts             点击、Draft.js 草稿注入、点赞、关注
│   ├── profile-probe.ts           主页 URL 判定与资料区按钮挑选（纯逻辑，可单测）
│   └── humanizer.ts               贝塞尔平滑滚动、随机延时、打字机输入
├── sidepanel/
│   ├── App.tsx                    Tab 容器 + 全局紧急制动
│   ├── components/                ManualMode / AutoMode / SettingsModal / ProfileCard / ui
│   └── hooks/useStorage.ts        storage 响应式 Hook + SW 调用封装
└── shared/
    ├── types.ts                   消息协议与配置类型（单一权威来源）
    ├── api.ts                     统一 LLM 客户端 + Prompt 模板引擎
    ├── storage.ts                 配置读写、深合并、预检、导入导出
    ├── constants.ts               默认配置、预设、X DOM 选择器
    └── utils.ts                   cn / 随机 / 指纹 / 格式化
```

## 使用须知

自动化操作存在**账号风险**。X 的服务条款禁止自动化交互行为，此插件仅用于个人学习与技术研究。请：

- 保持参数保守（低配额、长间隔、先跑草稿模式）
- 单轮数量与频率均低于真人正常使用水平
- 出现验证码或行为验证时立即停止
- 不要多开、不要 24 小时无人值守长时间运行

使用本工具产生的一切后果由使用者自行承担。
